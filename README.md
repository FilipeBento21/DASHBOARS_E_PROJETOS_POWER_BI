# 📊 Power BI Dashboards | Projetos e Evolução

Bem-vindo(a) ao meu repositório de projetos em Power BI!

Aqui compartilho meus estudos, práticas e projetos reais desenvolvidos ao longo da minha jornada com análise de dados.
Meu objetivo é mostrar não só o resultado final dos dashboards, mas também a evolução contínua das minhas habilidades e do meu raciocínio analítico.

---

## ✨ Objetivos deste Repositório

✅ Reunir todos os dashboards já desenvolvidos, com atualização e melhorias conforme minha evolução.  
✅ Adicionar novos projetos com base em estudos, desafios e experiências profissionais.  
✅ Documentar **todo o processo** de criação:  
- **Extração de dados** (conexão com fontes variadas)  
- **Transformação e limpeza** (tratamento de dados no Power Query)  
- **Visualização e apresentação** (uso de gráficos, KPIs, filtros, bookmarks e mais)

---

## 📂 Estrutura dos Projetos

Cada projeto terá sua própria pasta com os seguintes itens:

- `📁 Dados`: fonte dos dados utilizados (quando possível compartilhar)
- `📄 Descrição.md`: explicação do objetivo do dashboard
- `📊 Arquivo.pbix`: arquivo Power BI do projeto
- `📸 Capturas de tela`: imagens do dashboard final
- `🔍 Etapas.md`: documento explicando as 3 fases:
  1. **Extração** dos dados
  2. **Transformação/Limpeza** com Power Query
  3. **Modelagem/Visualização** no Power BI
